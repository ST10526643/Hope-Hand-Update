# HopeHands Foundation – NGO Website

## Project Overview
HopeHands Foundation is a non-profit organisation website developed as part of a school web development project. The website provides information about the organisation, its mission, services, and ways for visitors to get in touch.

The project focuses on creating a professional, user-friendly website with clear navigation and an accessible layout.

## Website Pages
- *Home:* Introduction to HopeHands Foundation.
- *About:* Information about the organisation and its mission.
- *Services:* Overview of the services and support offered.
- *Enquiry:* Allows visitors to make enquiries.
- *Contact:* Provides contact information for the organisation.

## Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and layout.
- JavaScript – Interactive functionality.

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser.
4. Alternatively, use the Live Server extension in VS Code.
